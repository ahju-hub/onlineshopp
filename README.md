# 📱 Aplikasi Belanja Online

Aplikasi ini dirancang untuk memberikan pengalaman belanja fashion yang mudah, cepat, dan menyenangkan langsung dari smartphone pengguna.

---

## 🧭 Alur Pengguna (User Flow)

1. **Welcome Screen** ➝ Klik "Let's Get Started"
2. **Home Screen** ➝ Pilih produk
3. **Product Detail Screen** ➝ Klik "Add to Cart"
4. **Cart Screen** ➝ Klik "Check Out"

---

## 🖼️ 1. Welcome Screen

**Judul Scene:** "Welcome to Shopping App"  
**Deskripsi:**  
Tampilan awal yang menampilkan dua foto model fashion dan slogan promosi.

**Elemen UI:**
- Gambar dua model fashion (dalam lingkaran)
- Teks promosi: `"Your Shopping Destination for Everything"`
- Deskripsi singkat: `"Get personalized recommendations. Enjoy fast, free shipping"`
- Tombol `Let’s Get Started` (warna orange)
- Link `Sign In` kecil untuk pengguna yang sudah memiliki akun

**Aksi Pengguna:**
- Tekan `Let's Get Started` untuk lanjut ke Home
- Tekan `Sign In` untuk login

---

## 🏠 2. Home Screen

**Judul Scene:** "Beranda Utama"  
**Deskripsi:**  
Tampilan utama dengan pencarian, filter kategori, banner, dan produk populer.

**Elemen UI:**
- Sapaan pengguna (contoh: `Welcome Back, Tina Anderson`)
- Kolom pencarian (ikon kaca pembesar)
- Filter kategori: `All`, `Women`, `Men`, `Shoes`
- Banner iklan besar: `"Buy one, Get one for free."`
- Daftar produk populer (misalnya: Casual Shoes, Stylish Pad Shirt)

**Aksi Pengguna:**
- Filter produk berdasarkan kategori
- Klik produk untuk melihat detail
- Navigasi bawah: Home, Love/Favorite, Cart, Profile

---

## 👕 3. Product Detail Screen

**Judul Scene:** "Detail Produk"  
**Deskripsi:**  
Detail lengkap dari produk yang dipilih.

**Elemen UI:**
- Gambar besar produk (dengan beberapa warna)
- Pilihan warna (bulatan warna)
- Pilihan ukuran: `S`, `M`, `L`, `XL`
- Deskripsi produk (placeholder lorem ipsum)
- Harga asli dan harga diskon (dicoret)
- Tombol besar `Add to Cart`

**Aksi Pengguna:**
- Pilih warna dan ukuran
- Tekan `Add to Cart` untuk masukkan ke keranjang

---

## 🛒 4. Cart Screen

**Judul Scene:** "Keranjang Belanja"  
**Deskripsi:**  
Daftar semua produk yang dimasukkan sebelum checkout.

**Elemen UI:**
- List produk: nama, harga, jumlah
- Tombol + / - untuk ubah jumlah
- Ringkasan pembayaran:
  - Subtotal
  - Delivery Fee
  - Total Tax
  - Grand Total
- Tombol besar `Check Out` (warna orange)

**Aksi Pengguna:**
- Edit jumlah barang
- Tekan `Check Out` untuk lanjut ke pembayaran

---

## 📌 Catatan Tambahan

- Aplikasi ini cocok untuk pengguna yang suka berbelanja produk fashion secara praktis.
- UI dirancang modern dan responsif, dengan navigasi intuitif.
